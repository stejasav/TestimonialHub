Third-Party Website Demo

This demo illustrates how third-party websites can embed the TestimonialHub Widget using a customizable <iframe> snippet with accent color parameters.

Embed Code Snippet:

<iframe src="http://localhost:5173/widget?color=%231F3A3D" width="100%" height="480" frameborder="0" style="border-radius: 16px; overflow: hidden;"> </iframe>
